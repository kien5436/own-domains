# Platform Host Boundary Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Introduce behavior-preserving platform contracts and a compile-time facade so the daemon and CLI no longer depend directly on macOS host-integration types, without changing any artifact, diagnostic, or runtime behavior.

**Architecture:** Shared contracts live in `own-domains-daemon::platform`: `HostInspector`, `HostInstaller`, setup request/result types, and a runtime factory. macOS PF, resolver, manifest, trust, and sidecar details stay under `platform::macos`. The CLI gets a compile-time platform module that implements installer orchestration; future platforms add a sibling module instead of editing command dispatch.

**Tech Stack:** Rust 2024, Cargo workspace, existing `own-domains-daemon`, `own-domains-cli`, `own-domains-core`, and `own-domains-protocol` crates. No production dependencies are added.

**Spec:** `docs/superpowers/specs/2026-10-23-network-independent-macos-integration-design.md`

## Global Constraints

- One-time setup remains the only privileged operation; this plan introduces no privileged helper.
- No PF, resolver, manifest, trust-store, interface-discovery, or sidecar-target details may move into shared code.
- Existing macOS artifacts, manifest schema, diagnostics, exit codes, and user-visible output must remain byte-for-byte/equivalent.
- The daemon binary and CLI must not import `platform::macos` directly after this refactor.
- Non-macOS behavior remains unsupported setup and `runtimeUnavailable`.
- Do not change `settings.json`, the wire protocol, or the React frontend in this plan.
- Run `cargo test --workspace` before and after each task.
- The root `pnpm test` currently also collects `.worktrees/tauri-gui-migration` tests; do not use it as a pass/fail gate for this Rust-only refactor.

## Review Focus

- A preview run must never write host files, create the CA, or require root; only apply paths may do that.
- Every existing setup/uninstall exit code and message shape must survive the CLI extraction.
- The macOS anchor, resolver, PF composition, and manifest generated bytes must remain unchanged.
- The runtime facade must preserve `--settings-only` returning the unavailable backend.
- `HostInstaller` and `HostInspector` must remain object-safe and `Send + Sync`.

    pub path: PathBuf,
    pub backup_path: Option<PathBuf>,
}

#[derive(Clone, Debug, Eq, PartialEq)]

    pub actions: Vec<SetupAction>,
}

#[derive(Clone, Debug, Eq, PartialEq)]

    pub written: Vec<PathBuf>,
    pub unchanged: Vec<PathBuf>,
    pub backups: Vec<PathBuf>,

pub struct SetupFailure {
    pub message: String,
    pub unresolved: Vec<String>,
}

impl SetupFailure {
    pub fn new(message: impl Into<String>) -> Self {
        Self {
            message: message.into(),
            unresolved: Vec::new(),
        }
    }
}

impl std::fmt::Display for SetupFailure {
    fn fmt(&self, formatter: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        write!(formatter, "{}", self.message)
    }
}

impl std::error::Error for SetupFailure {}

pub trait HostInstaller: Send + Sync {
    fn preview_setup(&self, request: &SetupRequest) -> Result<SetupPreview, SetupFailure>;
    fn apply_setup(&self, request: &SetupRequest) -> Result<SetupApplyResult, SetupFailure>;
    fn preview_uninstall(&self, request: &UninstallRequest) -> Result<SetupPreview, SetupFailure>;
    fn apply_uninstall(&self, request: &UninstallRequest) -> Result<SetupApplyResult, SetupFailure>;
}

pub type SharedInstaller = Arc<dyn HostInstaller>;

- [ ] **Step 4: Implement the macOS installer**

In `macos.rs`, add:

```rust
use crate::privilege::setup_user;
use own_domains_daemon::platform::{
    HostInstaller, SetupApplyResult, SetupFailure, SetupPreview, SetupRequest, UninstallRequest,
};
use own_domains_daemon::platform::macos::{
    apply_setup as apply_macos_setup, apply_uninstall as apply_macos_uninstall,
    build_host_setup_plan, preview_setup as preview_macos_setup,
    preview_uninstall as preview_macos_uninstall, MacOsArchitecture, MacOsSetupOptions, RuntimePaths,
    SidecarManifest, SystemSetupHost,
};

pub(crate) struct MacOsHostInstaller;

impl HostInstaller for MacOsHostInstaller {
    fn preview_setup(&self, request: &SetupRequest) -> Result<SetupPreview, SetupFailure> {
        let (options, _) = setup_options(
            &request.state_directory,
            &request.lan_address,
            &request.interface,
        )
        .map_err(SetupFailure::new)?;
        let plan = build_host_setup_plan(&options).map_err(SetupFailure::new)?;
        preview_macos_setup(&plan, &SystemSetupHost).map_err(|error| SetupFailure {
            message: error.message,
            unresolved: error.unresolved,
        })
    }

    fn apply_setup(&self, request: &SetupRequest) -> Result<SetupApplyResult, SetupFailure> {
        let (options, paths) = setup_options(
            &request.state_directory,
            &request.lan_address,
            &request.interface,
        )
        .map_err(SetupFailure::new)?;
        let (user, _) = setup_user(false).map_err(SetupFailure::new)?;
        let plan = build_host_setup_plan(&options).map_err(SetupFailure::new)?;
        ensure_state_directory(&paths, &user).map_err(SetupFailure::new)?;
        ensure_caddy_ca(&paths, &user).map_err(SetupFailure::new)?;
        match apply_macos_setup(&plan, &SystemSetupHost) {
            Ok(result) => {
                let settings_path = paths.state_directory.join("settings.json");
                persist_network_address(
                    &paths.state_directory,
                    &options.lan_address.to_string(),
                )
                .and_then(|()| chown_path(&settings_path, user.user_id, user.group_id))
                .map_err(|error| SetupFailure::new(format!(
                    "unable to persist LAN address: {error}"
                )))?;
                Ok(result)
            }
            Err(error) => {
                let rollback = match apply_macos_uninstall(&paths, false, &SystemSetupHost) {
                    Ok(_) => "host setup rolled back".to_string(),
                    Err(rollback) => {
                        format!("host setup rollback failed: {}", rollback.message)
                    }
                };
                Err(SetupFailure::new(format!(
                    "{}; {rollback}",
                    error.message
                )))
            }
        }
    }

    fn preview_uninstall(&self, request: &UninstallRequest) -> Result<SetupPreview, SetupFailure> {
        let paths = uninstall_paths(&request.state_directory).map_err(SetupFailure::new)?;
        preview_macos_uninstall(&paths, request.purge, &SystemSetupHost).map_err(|error| {
            SetupFailure {
                message: error.message,
                unresolved: error.unresolved,
            }
        })
    }

    fn apply_uninstall(
        &self,
        request: &UninstallRequest,
    ) -> Result<SetupApplyResult, SetupFailure> {
        let paths = uninstall_paths(&request.state_directory).map_err(SetupFailure::new)?;
        apply_macos_uninstall(&paths, request.purge, &SystemSetupHost).map_err(|error| {
            SetupFailure {
                message: error.message,
                unresolved: error.unresolved,
            }
        })
    }
}

fn uninstall_paths(state_directory: &std::path::Path) -> Result<RuntimePaths, String> {
    let (user, _) = setup_user(false)?;
    let architecture = current_architecture();
    let resource_directory = std::env::current_exe()
        .map_err(|error| error.to_string())
        .and_then(|executable| installed_resource_directory(&executable))?;
    let state_directory = resolve_state_directory(state_directory, &user.home)?;
    let backup_directory = state_directory.join("backups").join("setup");
    RuntimePaths::new(
        state_directory,
        resource_directory,
        backup_directory,
        architecture,
    )
    .map_err(|error| error.to_string())
}
```

Add `current_architecture` and `target_triple` to `macos.rs` (moved from `command.rs`). The `setup_options` function must return `(MacOsSetupOptions, RuntimePaths)` exactly as before and use `crate::privilege::setup_user(false)`.

Do not duplicate the `apply_setup` rollback semantics: the current CLI rollback on settings persistence remains exactly as above.

fn execute_setup(
    apply: bool,
    state_directory: &Path,
    lan_address: &str,
    interface: &str,
) -> CommandOutput {
    if !cfg!(target_os = "macos") {
        return CommandOutput::error(3, "macOS host setup is unsupported on this platform");
    }
    let (_, identity) = match setup_user(apply) {
        Ok(user) => user,
        Err(error) => return CommandOutput::error(2, error),
    };
    if apply && identity.is_none() {
        return CommandOutput::error(2, "setup --apply must run as root through sudo");
    }
    let request = own_domains_daemon::platform::SetupRequest {
        state_directory: state_directory.to_path_buf(),
        lan_address: lan_address.to_string(),
        interface: interface.to_string(),
    };
    let installer = crate::platform::host_installer();
    if !apply {
        return match installer.preview_setup(&request) {
            Ok(preview) => CommandOutput::success(render_preview(&preview)),
            Err(error) => setup_failure(error),
        };
    }
    match installer.apply_setup(&request) {
        Ok(result) => CommandOutput::success(render_apply(&result)),
        Err(error) => setup_failure(error),
    }
}
```

fn render_preview(preview: &own_domains_daemon::platform::SetupPreview) -> String {
    preview
        .actions
        .iter()
        .map(|action| format!("{} {}", action.kind, action.path.display()))
        .collect::<Vec<_>>()
        .join("\n")
        + "\n"
}

fn render_apply(result: &own_domains_daemon::platform::SetupApplyResult) -> String {
    result
        .written
        .iter()
        .map(|path| format!("written {}", path.display()))
        .chain(
            result
                .unchanged
                .iter()
                .map(|path| format!("unchanged {}", path.display())),
        )
        .collect::<Vec<_>>()
        .join("\n")
        + "\n"
}
```
